# SmartCoffee

Site institucional da SmartCoffee, uma cafeteria que combina café de qualidade, tecnologia e um ambiente acolhedor.

## Acessar o site

O site é publicado pelo GitHub Pages:

https://luccasmanfredi.github.io/Projeto_SmartCoffee/

## Sobre o projeto

O site apresenta a cafeteria, seus produtos, o ambiente e uma seção de contato. Foi desenvolvido com HTML e CSS, sem etapa de build.

## Estrutura

```text
SMARTCOFFEE/
├── assets/       # Imagens do site
├── index.html    # Página principal
└── style.css     # Estilos
```

## Publicação

O workflow em `.github/workflows/pages.yml` publica automaticamente o conteúdo de `SMARTCOFFEE/` no GitHub Pages quando há alterações na branch `main`.

Para habilitar a publicação no repositório, acesse **Settings → Pages** e selecione **GitHub Actions** como fonte de build e implantação.

## Desenvolvimento local

Abra `SMARTCOFFEE/index.html` no navegador. Não é necessário instalar dependências.
